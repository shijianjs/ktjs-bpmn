<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:workflow" title="查看器与建模器">`BpmnViewer`、`BpmnNavigatedViewer`、`BpmnModeler`，都带完整的 `BaseViewer` 表面。</ktjs-feature>

<ktjs-feature icon="lucide:file-code" title="XML 往返">`importXML` 导入，`saveXML` / `saveSVG` 导出，各自带 promise 结果类型。</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="事件名有类型">`BpmnEvents` 覆盖导入/保存生命周期，`on` 返回可移除的 `BpmnListener`。</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="模型助手">`BpmnModelUtil.isType` / `isAnyType` / `businessObject` / `di`，每个扩展都会用到的判断。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">七个浏览器测试渲染真实图形，六个 Playwright 用例驱动演示页。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，并跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
