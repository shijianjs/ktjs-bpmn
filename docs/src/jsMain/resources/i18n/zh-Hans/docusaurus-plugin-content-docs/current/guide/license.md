# 许可证

## 本仓库

wrapper 与文档是 MIT，见仓库根目录的 `LICENSE`。

## 上游项目

`bpmn-js` 使用 MIT 许可证：

> The MIT License
> Copyright (c) 2014-present Camunda Services GmbH

本仓库同样是 MIT 许可，因此 wrapper 与被封装的包条款一致。上游版权声明已出现在模块 README 与
[LICENSE](https://github.com/shijianjs/ktjs-bpmn/blob/master/LICENSE) 中。

`bpmn-js` 整体就是 MIT：查看器、建模器、调色板、上下文菜单，以及它依赖的整套 `bpmn-moddle` /
`diagram-js` 都是开源实现，没有付费档。npm 依赖按上游发布的 `bpmn-js` 原样声明；本仓库不重新打包，
也不改变其许可。

上游源码：[https://github.com/bpmn-io/bpmn-js](https://github.com/bpmn-io/bpmn-js)

使用前请自行核对上游许可证原文；本页只是提示，不构成法律意见。
