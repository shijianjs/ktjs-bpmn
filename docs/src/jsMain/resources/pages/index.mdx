<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:workflow" title="Viewer and modeler">`BpmnViewer`, `BpmnNavigatedViewer` and `BpmnModeler`, each with the full `BaseViewer` surface.</ktjs-feature>

<ktjs-feature icon="lucide:file-code" title="Round-trip XML">`importXML` in, `saveXML` / `saveSVG` out, with the result types of each promise.</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="Typed event names">`BpmnEvents` covers the import/save lifecycle, and `on` hands back a removable `BpmnListener`.</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="Model helpers">`BpmnModelUtil.isType` / `isAnyType` / `businessObject` / `di` for the checks every extension starts with.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">Seven browser tests render real diagrams, and six Playwright checks drive the demo page.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
